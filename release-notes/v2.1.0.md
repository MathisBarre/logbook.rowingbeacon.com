Ce qui change pour votre club :

- Mises à jour automatiques : l'application propose elle-même les nouvelles versions et sauvegarde les données du club juste avant de les installer.
- Ponton : lever et coucher du soleil, rappel quand tous les bateaux sont rentrés, bateaux indisponibles visibles, places restantes dans l'équipage au départ.
- Sorties : saisissez une sortie oubliée (« Sortie déjà faite ») et corrigez une sortie déjà enregistrée.
- Avaries et Réservations de bateaux : deux modules à activer dans Gestion > Modules, compatibles avec efa2.
- Statistiques : tableau de bord, 29 rapports, rapport annuel imprimable, explorateur SQL et assistant IA facultatif.

Windows : seul l'installeur .exe est proposé, le MSI n'existe plus.
